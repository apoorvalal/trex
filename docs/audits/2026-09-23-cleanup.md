## Scope and result

This pass starts from Trex's actual default branch, `main`. It repairs numerical and statistical correctness problems while reducing duplicated implementation. It does not merge the separate Gaussian-tabular experiment or revive the policy-aligned CATE proposal.

The baseline test run produced **72 passes and one failure**: the California synthetic-control test depended on an untracked sibling checkout. The completed local run produces **131 passes**, with **58 additional tests**. Tests were executed with Python 3.12 in the shared Torch environment on Linux, including explicit CPU/CUDA comparisons on an RTX 5070. The wheel also built, imported outside the source tree and passed a fit/metric compatibility check. Line coverage is approximately **79%**; coverage is a measure of execution, not a proof of statistical validity.

The most consequential fixes are weighted least squares, fixed-effect inference, generic GMM derivatives, GEL covariance, multinomial-logit information, rare-event likelihoods, dynamic-choice counterfactual simulation, and unequal-sample distribution distances. No estimator is claimed to be universally validated. The coverage map and remaining limitations below distinguish independent reference comparisons from smoke tests.

## Linear regression and fixed effects

The previous linear estimator accepted weights but did not use them in its least-squares solve. It also computed FE standard errors from the original outcome/design rather than the within-model residuals/design. Classical variance used a centered residual variance, which is incorrect when no intercept is fitted.

The corrected WLS calculation uses the transformed design $A=W^{1/2}\widetilde X$ and response $b=W^{1/2}\widetilde y$, where tildes denote weighted FE absorption. With residual $r=\widetilde y-\widetilde X\widehat\beta$, the covariance calculations are

$$
\widehat V_{\mathrm{classical}}=(A'A)^{-1}\frac{r'Wr}{n-k},
$$

$$
\widehat V_{\mathrm{HC0}}=(A'A)^{-1}\left(\sum_i w_i^2\widetilde x_i\widetilde x_i'r_i^2\right)(A'A)^{-1},
\qquad \widehat V_{\mathrm{HC1}}=\frac{n}{n-k}\widehat V_{\mathrm{HC0}}.
$$

Here $k$ includes the rank of the absorbed effects, not just the number of reported slopes. One-way rank is the number of levels. Two-way rank uses the connected components of the incidence graph, so disconnected panels are handled correctly. Three-or-more-way rank uses a bounded level-space Gram calculation; above 2,048 combined levels the caller must supply `df_absorbed` rather than triggering an uncontrolled dense allocation. This is an explicit cost boundary, not an approximate rank silently substituted for the true one.

Weighted alternating projections now operate on all columns together, allocate by the number of levels rather than the largest identifier, and return the final converged update. String labels are accepted through `prepare_fixed_effects`. Nonconvergence and unidentified nonabsorbed regressors raise errors.

**API semantics:** weights are strictly positive analytic/WLS weights, not frequency weights; zero weights must be filtered explicitly. `se` supports `classical`, `HC0`, `HC1`, or `None`. The full coefficient covariance is available in `params['vcov']`. FE-absorbed columns retain zero slots for compatibility. `predict(X)` remains slope-only; it is now documented as such. `fitted_values_` includes the fitted training-sample effects. This pass does not add a new out-of-sample FE level-prediction API or clustered covariance estimator.

Reference tests compare coefficients, covariance diagonals and fitted values against Statsmodels, R `lm`, R `sandwich::vcovHC`, and R `fixest::feols` with explicit full-FE degrees-of-freedom correction. No-intercept inference and disconnected FE graphs have dedicated checks.

## GMM and generalized empirical likelihood

### GMM

Both backends now share weighting validation, covariance construction and inference. They retain separate optimization/derivative engines: NumPy/SciPy finite differences and Torch autodiff. The default Torch optimization uses strong-Wolfe LBFGS. Direct construction of `GMMEstimatorTorch` also stays on the Torch backend rather than accidentally dispatching to SciPy.

Previously, the supplied moment function could be nonlinear, but its Jacobian was always replaced by the linear-IV formula $-Z'X/n$. Custom NumPy weighting matrices could also trigger an ambiguous-array truth-value exception, and a single moment produced a scalar covariance where a matrix was required.

For $\bar g(\theta)=n^{-1}\sum_i g_i(\theta)$, the implementation now differentiates the actual callback and uses

$$
\widehat V=\frac{1}{n}(G'WG)^{-1}G'W\widehat\Omega WG(G'WG)^{-1}.
$$

The covariance convention is explicit: uncentered moment second products with divisor $n$ (HC0). This changes the old centered `n-1` convention. `iid=False` selects a Bartlett/Newey–West long-run covariance for **both** optimal weighting and final inference. `max_lags` permits a reproducible lag choice. `covariance_` is the finite-sample coefficient covariance; the legacy `vtheta_` attribute remains on its asymptotic scale, so `covariance_ = vtheta_ / n`.

Tests compare IV estimates and covariance with `linearmodels.IVGMM`, custom fixed weights, a nonlinear log-mean moment with an analytic derivative, and HAC accumulation with Statsmodels. Rank-deficient weighting/identification is rejected rather than hidden behind an invented ridge. Initial coefficients default to deterministic zeros; `init_params` allows the parameter dimension to differ from the number of columns of `x`. Optimization failure is explicit.

### GEL

The old covariance multiplied a $q\times p$ derivative matrix in the wrong orientation and with the wrong Hessian sign. Its fallback could return a $q\times q$ moment covariance as if it were a $p\times p$ parameter covariance.

The corrected, correctly-specified first-order covariance is $(G'\Omega^{-1}G)^{-1}/n$. EL, exponential tilting and CUE share this asymptotic formula. There is no shape-changing fallback. Empirical likelihood respects its domain $g_i'\lambda<1$ rather than clipping invalid arguments. The inner problem uses damped Newton steps with a feasibility-preserving line search; the outer derivative uses the envelope theorem.

R `gmm::gel` independently supplies EL/ET/CUE coefficient references for an overidentified mean/variance example. A just-identified mean example verifies the covariance analytically; the overidentified covariance is checked against a separate analytic moment Jacobian. The tests **do not claim exact finite-sample equality to R's reweighted covariance**, or misspecification-robust GEL inference. Moment sets without a feasible finite optimum can still fail; they are reported as failures, not plausible-looking estimates.

## Static and dynamic choice

**Probit:** the likelihood uses the log normal CDF directly. Adding epsilon to a tiny CDF previously capped the loss and erased precisely the rare-event gradients needed by the optimizer. Expected information is also evaluated in log space.

**Multinomial logit:** the identity-matrix Fisher placeholder is replaced by the full block information. With class probabilities $p_{ia}$, each observation contributes $x_ix_i'\otimes[\operatorname{diag}(p_i)-p_ip_i']$ for non-base alternatives. Coefficients and covariance match Statsmodels after reconciling its first-category normalization with Trex's last-category normalization and parameter ordering. Covariance indexes the row-major flattened `(feature, non-base class)` coefficient array.

GLM coefficient/covariance checks cover R and Statsmodels logistic/Poisson fits. Estimator initialization no longer resets the caller's global random seed. Pytest seeds are instead reset explicitly per test, avoiding dependence on test order. Low-rank logit no longer returns a fabricated identity information matrix: its inference method explicitly raises `NotImplementedError`.

**Rust NFXP:** the observed-action likelihood is computed by gathering from `log_softmax`, not by logging probability plus epsilon. Optimization uses a mean objective and line search; value iteration and its gradients retain the structural Bellman equation. Three separately simulated 20,000-observation Markov panels match independent NumPy Bellman/SciPy likelihood fits within coefficient tolerance $2\times10^{-4}$ and probability tolerance $2\times10^{-5}$.

**Hotz–Miller:** first-stage frequency calculations are vectorized and device-correct; CCP/transition dtypes are aligned, zero-probability entropy uses $0\log0=0$, and inversion solves a linear system instead of materializing its inverse. Automatic CCP estimates are refreshed on refit. An independent NumPy linear-system calculation checks the inversion.

Both estimators now share pure flow-utility construction and post-fit prediction/simulation. Linear state features survive fitting. Counterfactuals construct altered utilities explicitly, solve the altered Bellman problem and simulate those probabilities, without mutating fitted parameters. They start from each individual's earliest recorded state, not the list of unique states; the default horizon is the largest observed period count, not the largest calendar label. An explicit horizon is advisable for unbalanced panels. A near-certain replacement policy test verifies that simulated actions change and the baseline model does not.

For Hotz–Miller, post-fit predictions are **structural equilibrium predictions** from the estimated utility, not the empirical first-stage CCP table. Policy changes therefore re-solve behavior rather than freezing the first-stage probabilities. Dynamic-choice standard errors, joint transition/utility estimation and arbitrary neural utility adapters are still outside the implemented API. Utility normalizations and identification remain the modeler's responsibility.

## Tabular, panel and shared-code cleanup

`TabularTransformer` now lives in `trex.preprocessing`; distribution diagnostics live in `trex.metrics`. Existing imports from `trex` and `trex.simdgp` continue to work. The transform rejects reordered dataframe columns, incompatible widths, nonfinite values and invalid binary-column declarations instead of silently transforming the wrong variables. Binary rounding/nonnegative clipping remain postprocessing, **not** a mixed discrete/continuous likelihood.

The old sliced Wasserstein implementation sorted both projected samples and truncated the longer one. The new implementation integrates the empirical one-dimensional distributions through SciPy for unequal sizes, retaining the efficient exact sorted calculation for equal sizes. Symmetry and independent directional SciPy references are tested. Comparisons still depend on feature scale: training-set standardization remains important for mixed-unit tables.

Duplicated tensor and optimizer helpers are consolidated in `trex._utils`. Scalar inputs now enter the requested dtype directly, avoiding an intermediate float32 rounding step. Kernel matrices and moment criteria match SciPy/NumPy at float64 precision.

Further checks cover sklearn isotonic projection and nearest neighbours, linear sieve minimum distance versus `linearmodels.IV2SLS`, rank-zero latent-factor GLMs versus Statsmodels, and full-observation nuclear-norm completion versus NumPy singular-value thresholding. The existing California panel comparison now runs from a checked-in, attributed fixture. It tests the finite-iteration synthdid-style estimates, not a new guarantee that Frank–Wolfe has reached every optimization optimum.

Panel routines reject invalid observed values; disabling an additive effect leaves its reported component zero. Grouped-FE embeddings reject missing unit/time cells rather than silently treating missing data as zero. Duplicate observed cells retain averaging behavior. These embeddings require a complete panel after explicit preprocessing. GAN, PTGAN, diffusion and optional language-model wrappers retain their previous architecture; this pass validates small fit/sample paths and diagnostics, not training quality or causal fidelity.

## Reproduction and CI

Python test/reference dependencies are in the existing `test` extra in `pyproject.toml`. SciPy and pandas are runtime dependencies because core modules import them; Statsmodels and linearmodels are test dependencies. No R package is incorrectly represented as a pip dependency.

```bash
python -m pip install -e '.[test]'
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m pytest
python benchmarks/correctness_cleanup_audit.py --output tmp/cleanup-diagnostics.json
```

Regenerate the R inputs and references independently:

```r
install.packages(c("jsonlite", "sandwich", "fixest", "gmm"))
```

```bash
Rscript tests/reference/generate_r_fixtures.R
Rscript tests/reference/generate_r_gel.R
python -m pytest tests/test_linear_reference.py tests/test_mle_reference.py tests/test_gel_reference.py
```

[Hosted Python 3.10/3.12 and R-regeneration CI passed](https://github.com/apoorvalal/trex/actions/runs/35964203393); [the documentation build passed](https://github.com/apoorvalal/trex/actions/runs/35964203215) independently.

The ordinary Python suite is offline after installation: fixtures are committed and tests do not download data. CI includes Python 3.10 and 3.12 jobs plus a separate job that installs R packages, regenerates the fixture data and reruns the relevant Python comparisons. CUDA tests skip explicitly on CPU-only runners. The existing documentation workflow remains separate.

Local reference versions: Torch 2.9.1, NumPy 2.4.2, SciPy 1.17.0, Statsmodels 0.14.6, linearmodels 7.0, sklearn 1.8.0, pytest 9.0.2; R 4.5.0, sandwich 3.1.1, fixest 0.12.1, gmm 1.9-1. The R script accepts both the older and newer `fixest::ssc` argument names.

## Review boundaries

The changes are organized as focused commits: portable test infrastructure; weighted/FE regression; GMM; GEL; static likelihood/information; dynamic-choice post-fit behavior; tabular modules/metrics; shared utilities/panel guards; device/refit tests; independent R CI; and these audit artifacts.

Important remaining work is deliberately visible:

- No standard errors for dynamic choice or low-rank factorized logit.
- No new cluster-robust linear covariance, causal IFE/MC estimator, heterogeneous DID or imputation inference API.
- No guarantee of global optimization for nonconvex latent-factor models or neural generators.
- No validation of large-model Hugging Face/QLoRA generation, MPS float64 execution, distributed execution, or large-library memory scaling.
- Isotonic/kernel/nearest-neighbour primitive agreement is not a full replication of every original research estimator or its asymptotic theory.
- About 21% of executable lines remain uncovered, concentrated partly in optional language-model paths, summaries, uncommon inputs and alternative inference branches. Passing this suite is a substantial regression barrier, not a blanket correctness certification.
