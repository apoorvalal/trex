API reference

Signatures and public methods are generated from this checkout. Start with the method selection guide for assumptions, data shapes and inference limits. Inherited methods may be unimplemented for a particular estimator; a signature alone is not a claim of support. Edit Python docstrings or the API inventory, not these generated pages.

Unconditional moments

GMM backends, GEL and their criterion functions.

gmm.gmm.GMMEstimatorScipy
gmm.gmm.GMMEstimatorTorch
gmm.gmm.moment_covariance Uncentered long-run covariance of observation-level moment vectors.
gmm.GELEstimator Generalized empirical likelihood estimator for vector-valued moments.
gmm.rho_el Empirical Likelihood (EL): rho(v) = log(1-v)

gmm.rho_cue Continuously Updated Estimator (CUE): rho(v) = -0.5*v^2 - v
gmm.ScalarIVCUE Scalar CUE objective (a-beta*b)' Omega(beta)^-1 (a-beta*b).
gmm.PolynomialCUEResult Candidate enumeration result; beta=inf means no selected finite fit.
