# Reference data

`california_prop99.csv` is the California tobacco panel distributed by
[synth-inference/synthdid](https://github.com/synth-inference/synthdid), commit
`70c1ce3eac58e28c30b67435ca377bb48baa9b8a`, `data/california_prop99.csv`.
Its upstream license is retained as `SYNTHDID-LICENSE`.

This small, public fixture replaces a test dependency on an untracked sibling
checkout. The empirical point-estimate test can now run offline in a fresh clone.
