# Reference data

`california_prop99.csv` is the California tobacco panel distributed by
[synth-inference/synthdid](https://github.com/synth-inference/synthdid), commit
`70c1ce3eac58e28c30b67435ca377bb48baa9b8a`, `data/california_prop99.csv`.
Its upstream license is retained as `SYNTHDID-LICENSE`.

This small, public fixture replaces a test dependency on an untracked sibling
checkout. The empirical point-estimate test can now run offline in a fresh clone.

`r_regression_input.csv` and `r_regression_reference.json` are deterministic,
synthetic R-generated fixtures. Rebuild them with
`Rscript tests/reference/generate_r_fixtures.R` (jsonlite, sandwich, fixest).
They cover OLS, no-intercept OLS, WLS, weighted two-way fixed effects, logit and
Poisson. Covariance corrections are specified explicitly in the generator.

`r_gel_input.csv` and `r_gel_reference.json` are generated by
`Rscript tests/reference/generate_r_gel.R` (gmm and jsonlite). They cover the EL,
ET and CUE coefficient estimates of an overidentified moment model. GEL tests
compare coefficients to R and first-order covariance to a separate analytic
Jacobian; R's finite-sample reweighted covariance is retained for inspection,
not asserted to be identical.

Both JSON files record R/package versions and the generating command. The
R-reference CI job regenerates these rather than merely reading saved numbers.
